# Noty

An infinite canvas for everything you are learning. Free, offline, for Windows.

## Download

[Download Noty for Windows](https://github.com/Noty-by-ahmad/noty/releases/download/v1.0.0/Noty-Setup-New.exe)

## Install

1. Click the download link above and save `Noty-Setup-New.exe` (about 122 MB).
2. Run the file. If Windows SmartScreen appears, choose **More info - Run anyway**.
3. The installer adds Noty to your Start Menu and creates a Desktop shortcut.
4. Open Noty from the Desktop shortcut.

Requires 64-bit Windows 10 or later. Free forever, no account needed.
